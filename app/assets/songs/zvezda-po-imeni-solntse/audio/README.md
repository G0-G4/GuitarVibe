# Backing audio (local)

Expected file:

```
solnce.mp3
```

Place a local copy of the track here (same folder as this README).

Commercial recordings are **gitignored** — do not commit copyrighted audio to the public repo.

Example (from your machine):

```bash
cp ~/Downloads/solnce.mp3 \
  app/assets/songs/zvezda-po-imeni-solntse/audio/solnce.mp3
```

If the file is missing, ChordCoach falls back to metronome + guitar guide.
